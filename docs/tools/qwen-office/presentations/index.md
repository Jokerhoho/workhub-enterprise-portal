# 05 · PPT 汇报

PPT 的目标不是“把报告切成很多页”，而是让听众在限定时间内理解问题并做出决定。先设计故事线，再生成页面。

## 先定义五件事

| 要素 | 示例 |
| --- | --- |
| 受众 | 部门管理层 |
| 目标 | 决定是否增加下一季度预算 |
| 时长 | 10 分钟 |
| 页数 | 8 页正文 + 附录 |
| 必须回答 | 现状、原因、方案、投入、风险、决策 |

## 先要逐页提纲

```text
请根据附件设计一份 8 页管理层汇报。
先只输出逐页提纲，每页包含：
- 页面标题，必须是一句结论；
- 这一页回答的问题；
- 使用的数据或证据；
- 推荐图表或视觉形式；
- 演讲者要说明的一句话。

不要生成 PPT，等我确认故事线。
```

## 一条可靠故事线

1. 结论摘要：希望听众记住什么。
2. 目标与口径：讨论范围是什么。
3. 现状：最重要的变化。
4. 原因：用证据解释驱动因素。
5. 方案：可选择的路径。
6. 计划：里程碑、负责人和资源。
7. 风险：什么可能失败以及如何应对。
8. 决策：今天需要谁确认什么。

## 生成时的版式约束

```text
根据已确认提纲生成 16:9 PPT。
要求：
- 每页只表达一个核心观点；
- 标题写结论，不写“数据分析”一类主题词；
- 正文不超过 5 个要点；
- 图表标注单位、时间范围和来源；
- 使用附件中的品牌颜色和字体；
- 没有素材时使用简洁图形，不生成虚构照片；
- 交付可编辑 PPT 和逐页演讲备注。
```

## 修改时锁定不变项

例如：“只调整第 4 页图表与第 7 页风险表，所有数字、页序、品牌颜色和其他页面保持不变。”这样可以避免一次局部修改破坏整套内容。

## 逐页验收

- 标题能否单独构成完整结论。
- 图表是否比表格或文字更清楚。
- 数字是否与底稿一致。
- 字号能否在投影状态阅读。
- 每页是否在 45–90 秒内讲清。
- 最后一页是否明确需要的决定。
