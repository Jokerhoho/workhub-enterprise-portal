# 02 · 写清复杂任务

千问办公能执行多步骤任务，但它无法替你决定“什么结果才算合格”。复杂任务的关键不是写很长，而是把边界和验收标准写清楚。

## 六个必需字段

| 字段 | 要回答的问题 | 示例 |
| --- | --- | --- |
| 背景 | 为什么做、用于什么决定 | 为季度经营会准备复盘 |
| 目标 | 最终要解决什么问题 | 解释收入下降的主要驱动 |
| 输入 | 只能使用哪些资料 | 销售表、上月报告、会议纪要 |
| 要求 | 结构、口径、风格、限制 | 面向管理层，数字可追溯 |
| 交付 | 需要哪些文件 | 分析表、报告、8 页 PPT |
| 验收 | 如何判断正确 | 三份成果数字和口径一致 |

## 通用任务模板

```text
背景：【任务为什么存在、最终支持什么决定】
目标：【要解决的问题】
输入：【附件、网盘文件、时间范围】
要求：
- 必须包含：【内容】
- 不得包含：【边界】
- 事实规则：无法确认时标记“待核实”，不要补写
交付：【文件类型、数量、页数、命名规则】
验收：
- 【可观察标准 1】
- 【可观察标准 2】

请先检查材料并给出执行计划、缺失信息和风险；我确认后再生成完整成果。
```

## 复杂任务分五段

1. **盘点材料**：列文件、时间范围、版本和缺失项。
2. **形成底稿**：先提取事实、口径和待确认问题。
3. **确认结构**：先看报告目录、分析框架或 PPT 故事线。
4. **分步制作**：一次完成一个成果，避免错误同时扩散。
5. **交叉复核**：最终检查数字、术语、结论和来源是否一致。

## 多轮修改怎么说

不要说“再优化一下”。指出具体对象、问题和保持不变的部分：

```text
只修改第 3–5 页：
- 第 3 页把三段文字改成一张时间线；
- 第 4 页保留所有数字，只调整图表类型；
- 第 5 页补充风险负责人和截止时间。
其他页面的结构、数字和颜色保持不变。
修改后列出变更清单。
```

## 先问再做的四类情况

- 材料之间存在冲突。
- 统计口径或时间范围不明确。
- 任务涉及外部发布、批量修改或删除。
- 用户要求的交付与现有资料不匹配。

## 最终自检指令

```text
交付前请做一次独立自检，不要继续润色：
1. 列出所有关键数字及其来源；
2. 检查时间范围、单位、专有名词是否一致；
3. 找出材料无法支持的结论；
4. 标记仍需人工确认的内容；
5. 对照我的验收标准逐项给出“通过 / 未通过”。
```
