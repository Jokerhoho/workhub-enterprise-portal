# 千问办公快速上手

千问办公适合把资料、要求和交付标准组织成一个完整办公任务，产出可继续编辑的文档、表格、演示或网页。它提供网页端、桌面端以及钉钉内入口；不同账号、版本和授权范围可能有所差异。

::: tip 适合从这里开始
第一次使用时，先选一个低风险、结果容易检查的任务，例如整理会议纪要、分析脱敏后的表格，或把已有报告改成汇报提纲。
:::

## 适用场景

| 场景 | 可以交给千问办公做什么 | 人工重点检查 |
| --- | --- | --- |
| 文档 | 起草、改写、总结、提取要点、调整结构 | 事实、口径、语气、引用来源 |
| 表格 | 清洗数据、分类汇总、趋势分析、生成图表 | 公式、单位、缺失值、统计口径 |
| 演示 | 根据材料生成提纲与 PPT，再继续编辑 | 页数、结构、数据、品牌规范 |
| 资料整理 | 合并多份材料，输出结论和待办 | 是否遗漏、是否混入过期信息 |

## 5 分钟完成第一个任务

1. 打开[千问办公网页端](https://qwenwork.cn/signin)，或从企业已开放的钉钉入口进入。
2. 新建任务，上传允许处理的材料。含敏感信息时，先脱敏并确认公司制度。
3. 用一句话说明目标，再补充受众、格式、篇幅、截止时间和必须遵守的口径。
4. 先让它给出执行计划；确认无误后再生成完整成果。
5. 下载或在线检查结果，按本页验收清单逐项复核。

## 可直接复制的任务模板

### 把资料整理成报告

```text
请根据我提供的资料，整理一份面向【受众】的【报告类型】。
目标：【这份报告要支持什么决定】
结构：【必须包含的章节】
篇幅与格式：【字数、文件类型、版式要求】
事实要求：只使用资料中能够确认的信息；无法确认的内容标记“待核实”。
交付前请自检：数据口径、时间范围、专有名词和结论是否一致。
```

### 分析表格并制作周会汇报

```text
请分析附件中的【数据主题】，时间范围为【起止日期】。
先检查空值、重复值、单位和异常值，再输出：
1. 三个最重要的变化；
2. 每个变化的证据和可能原因；
3. 需要业务负责人确认的问题；
4. 一份【页数】页、适合周会的 PPT。
不要改写原始数据；所有图表注明单位、时间范围和数据来源。
```

### 把会议记录变成行动清单

```text
请把这份会议记录整理为：决策、待办、负责人、截止时间、风险、待确认事项。
没有明确负责人或日期的内容不要猜测，统一标记“待确认”。
最后生成一段不超过 200 字的会议结论，供群内同步。
```

## 三个可直接落地的案例

### 案例一：月度经营复盘包

上传脱敏后的经营表、上月报告和汇报模板，先让千问办公检查字段、单位、缺失值和统计口径，再依次生成事实底稿、完整报告和 8 页管理层 PPT。最后要求它交叉核对三份成果中的所有关键数字。

### 案例二：政策资料变成执行清单

```text
请整理附件中的政策与内部说明，输出：
1. 适用对象、有效时间和关键要求；
2. 对现有流程的影响；
3. 按部门划分的执行清单；
4. 需要法务、财务或负责人确认的问题。
每条结论标注材料来源；内容冲突时并列展示，不自行判断。
```

### 案例三：一份材料，多种交付

先生成面向执行团队的详细文档，再生成面向管理层的精简 PPT，最后生成群内 200 字同步稿。三种成果使用同一事实底稿和术语表，避免在多次生成中出现数字、口径和专有名词漂移。

## 推荐工作节奏

资料盘点 → 计划确认 → 事实底稿 → 分步生成 → 交叉核对 → 人工发布。材料越多，越应该先锁定事实和口径，再生成版式漂亮的最终成果。

## 验收清单

- 文件能正常打开并继续编辑，格式与要求一致。
- 关键数字与原始材料逐项核对，公式和单位无误。
- 没有把推测写成事实；待确认内容已明确标记。
- 图表标题、时间范围、数据来源完整。
- 对外发布前已完成业务、品牌和合规复核。

## 安全边界

不要上传未经授权的客户隐私、员工敏感信息、密钥、账号口令或受限制数据。调用企业消息、文档、邮件、日程等连接能力前，先确认授权范围；任何对外发送、批量修改和正式发布都应保留人工确认。
