# 04 · 表格分析

表格任务最危险的做法是“上传后直接要结论”。正确顺序是先检查数据质量和口径，再分析，最后制作图表与汇报。

## 分析前的数据体检

要求千问办公先输出：

- 文件、工作表、字段和行数概览；
- 日期、金额、百分比和单位；
- 空值、重复值、异常值与格式混用；
- 主键或唯一标识是否可靠；
- 统计范围和口径是否明确；
- 不能自动判断的问题。

```text
先只读检查附件，不修改原表。
输出字段字典、数据质量报告和待确认问题。
未经我确认，不填补空值、不删除重复行、不调整异常值。
```

## 建立分析口径

| 项目 | 示例 |
| --- | --- |
| 时间范围 | 2026-01-01 至 2026-06-30 |
| 主指标 | 实收收入，不含税 |
| 对比基准 | 上月、去年同期、预算 |
| 分组维度 | 区域、产品、渠道 |
| 异常规则 | 环比变化超过 20% |
| 输出单位 | 万元，保留一位小数 |

## 从问题出发分析

不要说“分析一下”。使用业务问题：

```text
基于已确认口径，回答：
1. 收入变化主要由哪些区域、产品和渠道贡献？
2. 变化来自数量、价格还是结构？
3. 哪些异常需要业务负责人解释？
4. 下月最值得关注的三个指标是什么？

每个结论给出计算依据。相关性不要写成因果关系。
```

## 输出一个可复核工作簿

建议至少包含：

1. `README`：数据来源、时间、口径和使用说明；
2. `raw_data`：原始数据副本，不修改；
3. `clean_data`：清洗后的数据和处理标记；
4. `analysis`：公式、透视或汇总；
5. `charts`：用于汇报的图表；
6. `issues`：异常与待确认问题。

## 图表选择

| 问题 | 优先图表 |
| --- | --- |
| 时间趋势 | 折线图 |
| 类别比较 | 排序条形图 |
| 结构占比 | 堆叠条形图；类别很少时才用饼图 |
| 预算与实际 | 分组柱状图或差异桥 |
| 变量关系 | 散点图 |

## 复核指令

```text
请独立复核最终工作簿：
- 重新计算所有关键指标；
- 检查公式引用、单位、日期和筛选范围；
- 列出所有人工修正；
- 检查图表与底表是否一致；
- 随机抽取 10 条记录追溯到原始数据。
输出复核清单，不覆盖原文件。
```

## 验收

- 原始数据保留，所有处理可追踪。
- 公式、单位、时间范围和口径一致。
- 结论能追溯到具体表、字段和计算。
- 缺失值与异常值的处理有记录。
- 最终 Excel 可以继续筛选、修改和刷新。
