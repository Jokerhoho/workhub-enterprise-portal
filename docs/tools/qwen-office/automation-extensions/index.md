# 07 · 网页、自动化与扩展

当一次性任务已经稳定，再考虑发布网页、创建定时任务或安装扩展。先把人工流程跑通，才能知道自动化应该输入什么、输出什么、失败时怎么处理。

## 用 Pages 发布网页

QwenWork Pages 可以在任务对话中创建并发布静态或动态网页。适合个人主页、活动页、文档站、数据展示和轻量表单。

```text
请先创建一个静态内部项目主页，不要发布。
页面包含：项目目标、里程碑、负责人、最新进展、风险和资料入口。
使用 16:9 首屏，移动端可读，不包含任何客户隐私。
先给预览和发布前检查清单，我确认后再发布。
```

发布前检查域名、访问范围、表单去向、敏感信息、移动端和历史版本。动态页面还要检查数据库与第三方服务的权限。

## 创建定时任务

适合规律明确、输入稳定、失败可发现的工作：

- 每日行业简报；
- 每周竞品追踪；
- 固定数据报表；
- 指标异常检查；
- 一次性提醒与资料整理。

```text
创建一个每周一 09:00 的竞品动态任务。
只使用我指定的公开来源，覆盖过去 7 天。
输出：变化摘要、来源链接、影响判断、待确认问题。
如果来源不可访问或没有新信息，也要生成运行记录。
不要向外部群或邮件发送，结果只保留在任务中。
```

## 专家套件、Skill 与连接器

| 类型 | 解决什么问题 | 安装前检查 |
| --- | --- | --- |
| 专家套件 | 为岗位或场景组合完整能力 | 包含哪些能力、适用边界 |
| Skill | 固化一种专业工作方法 | 来源、指令、脚本和权限 |
| 连接器 | 接入账号、平台和数据 | 读写范围、凭据和外部动作 |

先在测试材料上安装和运行，确认触发条件与输出，再进入正式任务。

## IM 频道

桌面端可以作为管理中心，把任务接入组织允许的聊天平台。IM 会话的上下文相互隔离，结果回到发起任务的聊天窗口。上线前要确定开放或配对策略、允许使用的群、结果可见范围，以及机器人能否对外发送。

## 自动化验收

- 每次运行有独立记录。
- 无数据和失败同样有结果。
- 输出包含时间范围和来源。
- 外发、删除、批量修改等高风险动作需要确认。
- 有停用、修改和回退办法。
